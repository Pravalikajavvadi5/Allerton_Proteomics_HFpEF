# Allerton_Proteomics_HFpEF

This repository contains proteomics data from rat skeletal muscle samples, organized across two preprocessing stages.

## Data Files

**ZSF1_Rat_Proteomics_normalized_values**: Proteomics data normalized against an internal standard to correct for technical variation across samples and runs.

**ZSF1_Rat_Proteomics_filtered_preimputed_data**: Proteins with > 50% missing values in any group were removed, reducing the dataset from 1,912 to 1,674 proteins.
